# Cantinho da Lwinnie

Site pronto em HTML, CSS e JavaScript, responsivo para computador e celular.

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## Antes de publicar
No arquivo `script.js`, troque:
const whatsappNumber='244900000000';
pelo número real do WhatsApp, com código do país e sem espaços.

Também substitua:
- faixa etária
- horários
- localização
- Instagram
- informações de pagamento
- depoimentos de exemplo
- espaços da galeria pelas fotos reais

## Estrutura
- index.html
- style.css
- script.js
- assets/
